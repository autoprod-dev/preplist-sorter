Two ways to use this: One-time sort works exactly like a normal upload-and-go tool — nothing is saved anywhere, close the tab and it's gone (print or export first). Recipe database instead saves every dish's ingredients and per-pax quantities in this browser, reloading automatically every time you reopen this file — no re-uploading week to week, just tick dishes, enter pax and a date, and Generate. That database is stored via this browser's local storage, tied to this device/browser: export a backup occasionally (button above, in Recipe database mode) in case you switch computers, switch browsers, or clear browsing data. Sorting is keyword-based and won't be perfect — use the section dropdown on any row to move it. Prep stage is auto-assigned on a 4-day lead time (Day 1 collect/trim/wash/count, Day 2 cook/steam/roast, Day 3 portion/tray up/box off, Day 4 box-off continuation/production tools) based on each task's wording, then mapped onto real weekdays — in Recipe database mode, working backward from the event date you enter each week (a Saturday event runs Wed/Thu/Fri/Sat prep); in One-time sort mode, from a weekday named in the dish's tab (e.g. "Mains Beef Fillet Saturday") or set manually per dish. The "By prep day" view groups every dish's tasks by that real weekday across the whole week. Team leader names, section moves, pax counts, and day assignments are saved automatically to this browser as you work, so a refresh or an accidental close won't lose them — this week's pax/date selections in Recipe database mode are the one exception and reset each week by design. Export or print if you want a copy outside this browser.

Getting started

A quick walkthrough of the whole workflow, from raw files to a printed pack for the kitchen. Each step below matches a button or screen in the tool — work through them top to bottom the first few times, then use this page as a reference.

Preplist tab
01

Load a preplist

Drop an .xlsx preplist, or one or more production tool PDFs, into the dropzone. Every tab in a workbook is read as one dish; a PDF is read for its raw ingredients, with sub-recipes automatically broken out.

Choose "recipe database" mode if you want to build a reusable library you'll draw on every week, or "one-time sort" for a single preplist you won't reuse. Either way, your work saves automatically to this browser as you go.

02

Review the sorted categories

The tool splits every task into Vegetables, Proteins, Sauces/Purees/Gels, Garnishes, Big Jobs, and Box off — assign a team leader to each and switch to the "By prep day" view to see tasks grouped by real weekday.

03

Print or export

Section moves and team leader names save automatically to this browser as you go — a refresh or accidental close won't lose them. Print or export when you're ready for a copy outside the browser.
